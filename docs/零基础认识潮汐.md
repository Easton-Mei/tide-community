# 零基础认识潮汐：先知道它是怎么工作的

不懂代码也没关系。你可以把潮汐想成一个小型新闻编辑部：有人收集资料，有人整理底稿，有人写简报，还有人按时把简报送给你。

第一次使用只要记住：你负责告诉它关注哪些公司；潮汐负责收集、整理；开启 AI 后，模型再帮助你阅读和解释这些材料。

## 1. 潮汐由哪些部分组成？

**网页控制台：你的操作面板。** 添加股票、管理来源、点击生成、查看报告和设置时间，都在这里完成。它显示在浏览器里，但程序运行在你的电脑上。

**Python 采集管线：负责收集和整理资料。** “管线”就是一串按顺序工作的步骤：读取关注名单，访问新闻和公告来源，整理标题、时间和链接，去除重复，保存历史，生成底稿。Python 是运行这些步骤的程序语言，你不需要先学会编程。

**底稿：给人和 AI 都能看的材料清单。** 包含采集到的新闻、公告、行情时间和来源状态。它可以先生成一份规则报告，不需要模型密钥。你可以把它理解为“记者收回来的资料”，还不是 AI 的分析。

**AI 模型：阅读底稿，整理成更容易理解的日报。** 开启“AI 整理”后，潮汐把已收集的材料发给你配置的模型，让它概括变化、提示待核实事项、保留来源。模型没有收到的消息，不应当凭空补出来。

**Hermes Agent：能理解自然语言、调用工具做事的助手。** 例如你说“帮我关注苹果公司”，它可以调用潮汐的工具，把 AAPL 加入关注名单；你说“把这个 RSS 接进来”，它可以验证并保存来源。Hermes 是运行这个助手的软件，模型是它用来理解和判断的能力，两者不是同一件东西。

**定时器和推送：负责到点执行、把报告送出去。** 到设定时间，程序启动采集和报告流程；如果你启用了飞书推送，再由程序发送报告。

## 2. 采集资料和 AI 写日报，是分开的两步

```text
你填写关注的公司
        ↓
Python 去新闻源、公告源和行情接口取资料
        ↓
整理、去重、检查时间、记录失败来源
        ↓
生成底稿和规则报告 ← 不需要 AI，也能先看
        ↓（你开启了“AI 整理”）
模型阅读这份底稿，写成自然语言简报
        ↓
保存到本地 reports 文件夹
        ↓（你开启了推送）
程序把报告发到你自己的飞书机器人
```

因此，采集成功但模型失败时，底稿仍然可以保留；某个来源失败时，其他来源还可以继续采集。AI 写得再流畅，也不能弥补没有采集到的资料。

举个例子：你关注 NVDA，采集程序获取到官方发布的一条新闻，把标题、时间和原文链接放进底稿。AI 再根据这些材料写一段中文摘要。原文链接保留在报告里，方便你自己核实。

**这份开源版的默认实现：** 网页里的“AI 整理”直接调用你配置的模型接口；定时器也可以调用这条流程，不必先安装 Hermes。Hermes 用于你主动交给 Agent 的操作任务，并不是默认每天写报告的唯一执行者。报告发送由程序完成，不是模型自己连上飞书发送。

## 3. 先用哪一部分？按这个顺序就好

**第一步：看演示。** 安装 Python、启动潮汐，点“体验演示简报”。这一步用的是明确标记的虚构资料，不用联网和 API Key。

**第二步：让采集工作起来。** 添加公司，点“采集并生成”。看看是否真的拿到了新闻、哪些来源成功、哪些失败。没有 AI 也能得到规则报告。

**第三步：让 AI 帮你阅读。** 填好模型配置，再勾选“AI 整理”。先确认报告有内容、有来源，再考虑每天自动运行。

**第四步：需要自然语言操作时再装 Hermes。** 安装完成后，在 Agent 页面说出任务，并到关注名单或信息源页面核对结果。

**第五步：开启定时和推送。** 程序和电脑需要保持运行。关闭终端或电脑休眠期间，任务不会照常执行。

## 4. 几个常见词，知道意思就够了

**股票代码**：公司的查询标识，例如 NVDA。潮汐用它匹配公司与来源。

**信息源 / RSS**：消息从哪里来。RSS 可以理解为网站提供的“更新订阅入口”，程序能按固定格式读取。

**API**：程序之间交换信息的接口。模型 API 让潮汐能把材料交给模型，而不用你手动复制到聊天窗口。

**API Key**：访问模型服务的密钥，类似账号通行证。你应在潮汐自己的设置页输入，不要把它贴进公开聊天、截图或视频里。

**Base URL / 模型 ID**：分别是模型服务的接口地址和要用的模型名称，由服务商提供。

**终端**：在电脑上输入并执行命令的窗口。新手可以先用双击启动入口；需要 AI 帮忙安装时，AI 通常会使用终端执行步骤。

**本地运行**：程序和文件在你的电脑里。访问新闻源、调用云端模型、发送飞书消息仍然需要联网，不代表所有内容都只在电脑内部处理。

**费用**：基础采集与规则报告不需要模型费用；AI 报告和 Agent 会调用你选择的模型服务。辅助安装工具自己的会员或额度，与潮汐所用模型 API 的额度是两回事。

## 5. 还是不会安装？可以让能操作本机的 AI 帮忙

可以。先把潮汐解压，再用你已有的 AI 编程工具打开这个文件夹，让它读教程并执行安装步骤。这里需要的是**能读取本地项目、调用终端执行命令的工具和模式**。只有文字问答的聊天窗口通常只能教你操作，不能直接替你安装到电脑上。

国内用户可以了解以下工具；选一个你已经在用的就够了，不需要全装：

- **TRAE 桌面端**：打开本地潮汐文件夹，选择支持实际执行的 Agent / SOLO 模式，让它阅读项目教程后操作。
- **CodeBuddy IDE（腾讯）**：打开本地项目，使用具备文件与终端执行能力的 Agent 功能，让它按教程检查环境和启动服务。
- **Qoder**：打开本地项目，使用 Agent 模式；它支持调用终端完成构建和测试等操作，也可用于执行本项目的安装步骤。

各工具的模式名称、权限和可用功能可能随版本、地区或账户变化。看到命令确认时先核对它操作的是潮汐文件夹，再按提示授权。无需为了安装潮汐打开所有目录和所有命令的自动授权。

如果你已经在使用其他支持本地文件与终端操作的 AI 工具，也可以使用下面这段提示词。

## 6. 直接复制给安装助手的话

先在 AI 工具里打开解压后的潮汐文件夹，然后发送：

```text
请帮我在这台电脑上安装并启动当前文件夹里的 Tide Community（潮汐）。
我没有编程基础，请实际执行必要步骤，不要只给我一份命令清单。

先读 README.md、AGENTS.md、docs/快速开始.md 和 docs/Agent安装.md，
以本项目的真实说明为准，不要套用其他同名项目的安装方法。

请按顺序完成：
1. 确认操作系统、当前项目目录和 Python 版本。
   基础版需要 Python 3.11+，不需要额外 pip 依赖。
   缺少 Python 时说明所需步骤；遇到系统授权或安装界面，指导我完成。
2. 在这个独立文件夹内启动网页，端口占用时换一个空闲端口，告诉我打开哪个地址。
3. 实际生成一份离线演示报告，确认页面能显示、报告文件确实存在。
4. 再尝试一次真实采集，告诉我哪些来源成功、哪些未配置或失败。
5. 说明如何启动、停止，以及关闭终端或电脑休眠对定时任务的影响。

基础功能确认后，再指导我选择是否启用 AI 报告、Hermes 和飞书推送。
如果我需要 Hermes，请使用项目自带的独立安装器；Windows 按教程使用 WSL。
模型地址和模型名称可以指导我填写；API Key 和 Webhook 让我自己在设置页输入，
不要让我把密钥发到聊天里，也不要打印、复制或上传我的凭证文件。

不要覆盖我已有的潮汐或 Hermes 配置，不要改动无关项目和系统网络设置。
安装报错时先看实际错误再处理，不要仅因为命令执行了就说安装成功。
最后用简单中文告诉我：已完成什么、验证了什么、还需要我完成什么。
```

AI 工具能帮忙操作，也可能遇到需要你亲自完成的登录、管理员授权或网络问题。安装后至少亲眼看到一份演示报告，再检查一次真实采集结果。

## 7. 三种“AI”不要混在一起

**辅助安装的 AI 工具**：帮你把软件装好，使用的是它自己的账户、权限和额度。

**潮汐的报告模型**：读取采集底稿，使用你在潮汐设置里填的模型 API。

**潮汐里的 Hermes Agent**：理解你的操作要求，调用潮汐工具办事，也需要配置支持工具调用的模型。

它们可以使用不同的产品或模型。安装助手装好了潮汐，不等于潮汐已经自动获得模型额度；能生成规则报告，也不等于 Hermes 已安装。

# 第一期视频脚本：搭建你的第一个实用 Agent

建议标题：**我把每天看美股新闻这件事，交给了自己的第一个 Agent**。

以下时长是录制结构建议，不是用户安装耗时承诺。先在干净目录彩排一次，准备演示模式应对现场网络问题。

| 段落 | 建议时长 | 画面和操作 | 要讲清楚的内容 |
|---|---:|---|---|
| 结果开场 | 0:00–0:45 | 展示真实简报和原文链接 | 关注几家公司，每天知道有什么变化 |
| 下载启动 | 0:45–2:30 | 新目录解压，启动页面，生成演示 | 演示数据明确标记；不需要一开始配置所有工具 |
| 设置关注 | 2:30–4:00 | 添加 AAPL，看匹配源数量 | 股票代码 → 公司身份 → 行情/公告/官方源 |
| 真实采集 | 4:00–6:00 | 点击采集，展示进度和一个失败来源 | 来源失败不等于没有风险；源健康也是结果 |
| 加上模型 | 6:00–8:00 | 填接口和模型，生成 AI 简报 | 隐藏真实密钥；费用由服务商收取；保留原文底稿 |
| 开启 Agent | 8:00–11:00 | 独立安装 Hermes，任务新增关注 | Agent 理解请求，Python 执行，配置和数据库是持久状态 |
| 新增来源 | 11:00–13:00 | 粘贴官方 RSS，预览并接入；再演示 Agent | 新增标准源无需改核心代码；特殊网页并非保证支持 |
| 持续使用 | 13:00–15:00 | 设置时间，生成后推送到自己的演示群 | 程序需保持运行；电脑休眠不会按时执行 |
| 原理收尾 | 15:00–16:00 | 展示精简目录和流程 | 用户偏好 + 工具 + 历史 + 模型判断 + 调度 |

## 开场旁白示例

“我不想每天在十几个网站来回切换。我只想知道：我关注的几家公司，今天发生了什么？哪些值得我点开原文？所以我做了潮汐。这一期我们把它装到你自己的电脑上，再让它替你接入一个新信息源。”

## Agent 演示请求

1. “帮我关注 AAPL，告诉我已经有哪些来源。”
2. “验证微软官方博客的 RSS，接入并关联 MSFT；已经存在就不要重复添加。”
3. “看一下刚才采集失败的来源，说明是没配置、没内容还是连接失败。先不要修改设置。”

每次都回到页面核对真实配置或报告，别只展示 Agent 的成功回答。

## 录屏前检查

- 使用专门的演示运行目录，不录个人数据库、持仓、聊天历史。
- 密钥输入使用密码框；发布视频前检查终端、地址栏、通知有没有泄露 Webhook 或 API Key。
- 网络异常时切换离线示例，并清楚说这是演示，不要把样例当今日新闻。
- 费用不要报未经验证的固定金额，展示服务商用量页面或说明按用量计费。
- 视频描述附 GitHub Release、网盘包文件名、SHA256、Python 前置要求及教程文档。

## 可直接放视频简介的说明

潮汐 Tide Community 是一个本地运行的开源美股情报助手，包含可视化页面、Python 工具和可选 Hermes Agent。基础版需 Python 3.11+，无额外 pip 依赖；离线演示无需密钥。真实采集需联网，模型与 Hermes 功能需自行配置。不提供模型额度，不保证实时行情，不执行交易。

潮汐新手教程

潮汐是装在你自己电脑上的美股情报助手。你告诉它关注哪些公司，它去官方新闻、SEC 公告和公开行情里把消息收回来，整理成一份带原文链接的简报。

它是怎么工作的

你关注的公司
  ↓
① 采集：官方新闻、SEC 公告、公开行情（Python 程序完成，不需要 AI）
  ↓
② 底稿和规则报告，保存在 reports 文件夹（不开 AI 也能看）
  ↓
③ AI 整理成中文简报（可选）
  ↓
④ 推送到你的飞书群（可选）
  • 网页控制台：在浏览器里操作，程序运行在你自己的电脑上。
  • AI 整理（可选）：把底稿交给你配置的模型，写成中文简报。需要模型 API Key，按用量付费。
  • Hermes Agent（可选，进阶）：用一句话让它干活，比如「帮我关注苹果公司」，它会调用潮汐的工具去完成。

记住一句话：采集靠程序，AI 只负责阅读和写作。 没采集到的消息，AI 不应该凭空补出来；每条结论都可以点原文链接核实。

五步上手

  1. 安装 Python 3.11 或更新版本：到 Python 官网 下载。Windows 安装时勾选「Add python.exe to PATH」。
  2. 解压并启动：把压缩包解压到一个新文件夹（不要在压缩包里直接打开）。Mac 双击 启动潮汐.command，Windows 双击 启动潮汐.bat，Linux 运行 bash start.sh。浏览器会打开 http://127.0.0.1:8765。弹出的终端窗口不要关，它就是潮汐本体。
  3. 看演示：点「体验演示简报」。用的是标明「演示」的虚构数据，不联网、不花钱。
  4. 真实采集：默认已关注 NVDA、MSFT、GOOGL，点「采集并生成」。在「我的关注」里可以添加其他代码，比如 AAPL。想要 SEC 公告，在设置里填一个你自己的联系邮箱，例如 MyTide 你的邮箱。
  5. （可选）开启 AI：设置 →「模型连接」，填服务商给的 Base URL、模型名称和 API Key，保存后在首页勾选「AI 整理」。

想每天自动生成：在设置里打开「每天自动生成」并选好时间。

想定期检查突发消息：在设置里打开「突发提醒」。潮汐会每隔几分钟检查一次，首次检查只记录现有内容，之后发现新公告或新闻会显示在首页；配置飞书机器人并勾选推送后才会发送，还可以设置股价涨跌超过多少时提醒。默认不调用 AI，没有模型费用；也可以打开「推送前让 AI 复核」，只在出现新消息时让 AI 判断要不要提醒你，费用取决于你选择的模型和消息数量。

定时简报和突发提醒都只在潮汐开着、电脑醒着时运行；想全天候盯着，请在系统设置里关闭自动睡眠。

Mac 提示无法打开：右键 启动潮汐.command 选「打开」，或在终端进入文件夹运行 bash 启动潮汐.command。

不会装？让 AI 帮你装

需要的是能操作本机文件和终端的 AI 工具，例如 TRAE、CodeBuddy、Qoder 的 Agent 模式。普通聊天窗口只能教你，不能替你装。

用它打开解压后的潮汐文件夹，发送：

请帮我在这台电脑上安装并启动当前文件夹里的潮汐（Tide Community）。
我没有编程基础，请实际执行，不要只给我命令清单。先读 README.md 和 docs/新手教程.md，以本项目说明为准。

1. 检查 Python 版本（需要 3.11 或更新），缺少就指导我安装。
2. 在这个文件夹里启动网页，告诉我打开哪个地址。
3. 生成一份演示报告，确认页面能看到。
4. 试一次真实采集，告诉我哪些来源成功、哪些失败。

API Key 让我自己在设置页填，不要让我发给你，也不要读取或打印密钥文件。
不要改动其他项目和系统设置。最后用简单中文告诉我：做了什么、验证了什么、还差什么。

装好以后，至少亲眼看一次演示报告，再看一次真实采集结果。

三条安全提醒

  • API Key 只在潮汐的设置页里填，不要发进聊天、截图或视频。
  • 分享只转发原始压缩包，不要把自己用过的文件夹打包发人，里面有你的密钥和记录。
  • 开启 Hermes Agent 后，它能用你电脑的权限执行命令。 建议给它单独用一个额度很低的 API Key，只交给它潮汐相关的任务。

常见问题

  • 双击没反应：在终端进入文件夹运行 python3 tide.py web 看报错。多半是 Python 没装好、版本太旧，或没有完整解压。
  • 新闻数量是零：可能最近 24 小时确实没有新消息，也可能来源失败。去「信息源」看每个来源的状态。
  • 行情像是昨天的：休市或数据延迟。报告会标注行情时间，不要拿它当下单依据。
  • AI 没生成：检查 Base URL（通常以 /v1 结尾）、模型名称和账户额度。AI 失败时仍会保留规则报告。
  • 怎么停止、卸载：在终端按 Ctrl+C 停止；卸载就删掉整个文件夹，没有安装任何系统服务。

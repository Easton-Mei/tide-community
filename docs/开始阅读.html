快速开始：从零到第一份简报

1. 准备环境

需要一台可以安装 Python 的电脑。基础版支持 Python 3.11+，不需要 Node、Docker、数据库服务器或 pip 安装。

- macOS：安装 https://www.python.org/downloads/ 提供的 Python。若 HTTPS 提示证书错误，运行 Python 安装目录中的 Install Certificates.command。

- Windows：安装 Python，勾选“Add python.exe to PATH”，重新打开终端。

- Linux：使用发行版提供的 Python 3.11+。

在终端运行 python3 --version（Windows 可用 py -3 --version）确认。

2. 下载与启动

从 GitHub Release 或作者网盘下载 Tide-Community-0.1.0.zip，解压到你自己的新文件夹，例如 Documents/Tide。不要放到旧潮汐目录，不要从 ZIP 内直接打开。

- macOS：双击 启动潮汐.command。若系统阻止，右键打开，或在终端进入目录执行 bash 启动潮汐.command。

- Windows：双击 启动潮汐.bat。

- Linux：进入目录执行 bash start.sh。

浏览器会打开 http://127.0.0.1:8765。终端窗口要保持打开，它就是后台服务。端口冲突时用 python3 tide.py web --port 8767。

3. 先体验演示

首页点击「体验演示简报」。看到带“演示数据，非真实行情”标记的报告即可。

这一步不调用网络、不消耗模型费用，也不把示例写入真实情报数据库。样例的固定日期不代表当前市场。可以点击「下载 Markdown」验证导出。

4. 运行真实采集

默认关注 NVDA、MSFT、GOOGL。点击「采集并生成」，等待顶部进度结束。

- 官方 RSS 和公共行情不需要模型密钥。

- SEC 公告需要在设置中填写你自己的联系标识，例如 MyTide contact@example.com；不要照抄示例邮箱。

- 某个源失败会显示失败原因，其余源仍会处理。

- 窗口内无新闻时明确显示空缺，不会编造。

- 新加入来源的旧新闻会进入历史记录，但不会当成最近 24 小时新闻。

5. 加上模型理解

在设置的「模型连接」填服务商提供的 API Base URL、模型 ID 和 API Key。这里需要 OpenAI 兼容 Chat Completions 接口，网页订阅会员不必然包含 API 额度。

保存后在首页勾选「AI 整理」，再运行一次真实采集。模型输入包括公开新闻摘要、标题、链接、行情和来源状态；它不会收到你的 API Key 作为内容。

模型失败时保留规则报告并显示提示。AI 输出可能出错，原文和规则底稿始终可查。Token 用量保存在该份报告 JSON 的 usage 中，金额以服务商账单为准；本版没有跨服务商的金额硬上限。

6. 再开启 Agent

见 [Agent 安装](Agent安装.md)。基础报告和 AI 整理可先使用，不需要先学会 Agent 的全部配置。

常用操作

添加股票

进入「我的关注」，输入代码，例如 AAPL。潮汐会验证身份、添加关注并匹配内置官方源。

内置目录不等于 15 家公司都有新闻 RSS；页面会展示匹配源数量。没有精选官方源的公司仍可通过 SEC 获取申报文件、通过公共行情接口尝试获取快照。未在内置目录的代码需要 SEC 联系标识和网络验证。ETF、外汇、港股、A 股不属于此版公司识别范围。

移除公司后，对应的专用来源不再参与报告采集，除非该源还关联其他已关注公司；来源配置保留以便再次关注。通用来源不受影响。

接入信息源

1. 打开「信息源」，粘贴 RSS/Atom 地址或网站首页。

2. 点击检测。网页仅自动查找 HTML 中明确声明的 RSS/Atom，不进行全站爬取。

3. 阅读预览，核对来源身份和内容。

4. 可填写关联股票代码；留空表示通用来源。

5. 点击确认接入。接入时再验证一次，不可用则不保存。

试采集为空不代表出错，但界面会说明当前没有条目。无发布时间的内容不进入 24 小时日报。可在源码之外通过 Agent 请求寻找官方 RSS，不能保证任何网站都有订阅源。

不可信网页中的“请执行命令”“请读取密钥”等文本一律不是操作授权。

定时简报

设置中启用“每天自动生成”，填写时间与时区。默认系统时区。纽约时区依赖系统 IANA 时区数据库，可以自动跟随夏令时；Windows 若缺时区数据库，改用系统本地时区即可。

- 程序运行且电脑醒着才执行。

- 当天指定时间已经过去，启动后会补一次；不补过去多天。

- 每日一次；失败状态保留，不自动反复重试消耗 API。

- 可手动点击生成重试。手动生成不重置每日调度记录。

- 每个日历日运行，包括周末与休市日；行情时间和过期状态须自行注意。

- 本版不安装开机启动服务，关闭终端即停止调度。

飞书推送

在飞书群中添加“自定义机器人”，复制 Webhook，填入潮汐设置。若配置关键词，使用“潮汐”。本版不支持机器人签名校验。

先生成一份报告，再点首页“发送到飞书”。界面只会声称接口已接受，是否实际在目标群可见需要你打开群检查。再次发送同一份报告会跳过，防止重复通知。

报告较长时消息截短，全文留在本地。定时简报可以勾选自动推送。由于本工具不接入飞书读取权限，它不会读取群消息，也不能自动确认消息已被人阅读。

查看和备份

- 网页显示最近 30 份报告；更早报告仍在 reports。

- 每份 Markdown 可直接阅读，JSON 保存结构化来源、快照、模型用量。

- data/tide.sqlite 存情报去重历史。

- 备份个人环境时保留 config、reports、data，但 data 内有密钥和 Agent 会话，应存放在私有位置。

- 对外分享只使用官方原始发布包；开发者使用 scripts/build_release.py 打干净包。

删除密钥

网页留空表示“保留”，不会误清除。需要删除时先停止程序，在自己机器上编辑 data/secrets.json，将对应项值改为空字符串。不要把此文件发给他人。

安装独立 Hermes Agent

潮汐的采集、规则报告、AI 整理和网页不依赖 Hermes。Hermes 用于理解自然语言任务并调用潮汐工具，例如“帮我关注 AAPL”“查找微软官方 RSS 并接入”。

安装前

- Python 3.11+、Git、能访问 GitHub 和 Python 包源的网络。

- 支持 OpenAI 兼容 Chat Completions 工具调用的模型服务。

- 安装及模型调用需要网络。网盘包不包含 Hermes 运行时、Python 安装器或任何模型额度。

macOS / Linux 推荐路径

macOS 双击 安装 Hermes.command；或进入潮汐目录执行：

python3 scripts/install_hermes.py

安装器获取官方锁定提交 c4b2beea778ceca1462b91282589338b5e80781f，使用上游 uv.lock 在项目 .tools/hermes-venv 创建独立 Python 3.14 环境；必要时下载该解释器。不会调用全局 hermes setup，不会修改 ~/.hermes，不会启用旧 profile，也不会复制你的旧凭证。

下载失败时查看终端错误。GitHub 与包源可达性要分别检查。只使用你信任的网络或包源；本项目不附带代理、不自动改网络设置。

完成后重新启动潮汐。在设置里填写 Base URL、模型名称、API Key，并勾选允许 Agent 使用终端与文件工具。

已安装 Hermes

默认检测 PATH 中的 hermes；也可以在设置里填写可执行文件绝对路径。项目专用 .tools 安装优先于其他路径。运行参数依赖 chat -Q -q --provider --toolsets --max-turns，旧版本可能不兼容。

即使复用可执行程序，也会使用 data/hermes/profiles/tide-community 的独立 HERMES_HOME。模型密钥来自本项目设置，不继承其他服务商密钥。

Windows

基础潮汐网页、规则报告、RSS 和模型整理可以直接用 Windows Python。

本版 Hermes 安装器选择 WSL 路线：先按微软官方说明安装 WSL/Ubuntu，在 WSL 内准备 Python 3.11+、Git，将项目解压到 WSL 用户目录，执行上述安装命令，再在同一 WSL 目录运行 python3 tide.py web。Windows 浏览器访问输出的本地地址。

不要混用 Windows 的 Hermes 可执行路径和 WSL 的 Python 路径。本版不承诺 Hermes 原生 Windows 安装兼容性。

第一次 Agent 任务

打开「潮汐 Agent」，输入：

> 请添加 AAPL 到关注名单，并说明已匹配的来源。

完成后去「我的关注」核对结果。可靠的执行证据是实际配置和工具返回，不是 Agent 自己声称成功。

接着可以尝试：

> 请验证 https://blogs.microsoft.com/feed/，如果可用就接入并关联 MSFT。若已存在，不要重复创建。

权限和费用

独立 profile 是配置隔离，不是系统沙箱。Hermes 的终端和文件工具以当前系统用户权限运行。工作契约要求仅操作本项目，但不是强制文件系统隔离。不要让它处理恶意任务；更严格的隔离需另外部署容器或专用系统用户。

每个任务最多 8 轮、300 秒。时间限制和轮数限制不是费用硬上限，模型价格以服务商为准。遇到命令审批需求时，不会自动开启 yolo 模式绕过。

用户请求与工具结果会发送给所选模型服务商。会话在 data/hermes 下保留，不进入发布包。

常见问题

双击后没反应？

先在终端运行 python3 tide.py web（Windows 使用 py -3 tide.py web）看错误。检查 Python 版本、是否完整解压，以及 8765 端口是否被占用。

下载网盘包后完全不需要联网吗？

基础程序没有 pip 依赖，演示可以离线运行。真实源、模型和首次 Hermes 安装仍需要网络。Python 运行环境也需要预先安装。

公司已经添加，为什么新闻为零？

区分“配置覆盖”与“来源实际可用”。查看来源健康：可能最近 24 小时没有发布，也可能网络失败，或者没有匹配官方源。没有新闻不代表没有风险。

为什么 SEC 被跳过？

在设置中填写自己的应用名称和联系邮箱，例如 MyTide me@my-domain.com。SEC 会根据访问身份与频率限制自动请求。本版顺序采集，不需要 SEC API Key；但不保证任何网络环境都可访问。

行情看起来是昨天的？

公共接口可能返回休市前最后行情，或数据延迟。报告保留 quote_time，超过 120 分钟标记旧快照；这一阈值不代表交易所实时标准。不要用它作为下单依据。

AI 没生成，为什么还有报告？

模型失败会退回规则报告，并保留源健康和原文。检查 Base URL 是否是 API 根地址、模型 ID 是否存在、额度是否足够。API 根地址通常以 /v1 结尾，程序会附加 /chat/completions。

模型支持聊天但 Agent 不工作？

Agent 需要工具调用支持。查看 Agent 错误、Hermes 是否安装、独立环境能否使用该模型，以及终端工具是否允许。不能把普通模型聊天成功当成 Agent 工具执行成功。

添加来源找不到 RSS？

先打开官网找新闻中心、投资者关系或 RSS 标记。程序只识别标准订阅和网页声明。特殊网页需单独开发适配器，v0.1 不会自动改核心代码。

报告里的新闻时间来自哪里？

RSS/Atom 用源给出的发布时间；SEC 文件的日期精度为天，以 UTC 零点表示，会存在日边界误差；没有可信时间的内容不进入 24 小时窗口。采集时间不会冒充发布时间。

关闭浏览器还会运行吗？

只关浏览器、终端仍在，定时任务继续。关闭终端或睡眠就不执行。本版不自动安装系统服务。

换电脑、升级怎么做？

先停止潮汐，私下备份 config、data、reports。把新版本解压到新目录；需要保留历史时将这三个目录复制进去。不要覆盖正在运行的目录。不要共享包含 secrets.json 的备份。

如何停止或卸载？

终端按 Ctrl+C。需要卸载时删除自己的独立潮汐目录即可；没有安装全局服务。个人报告与配置如果还需要，请先备份。

03 定时简报

关闭程序或电脑休眠期间不会执行。当天错过时间会在启动后补一次；失败不会反复重试。

04 Hermes Agent

用于新增关注、接入来源和排错。Agent 可以使用当前用户的文件权限；只提交你信任的任务。独立数据保存在 data/hermes。

首次安装：运行文件夹中的「安装 Hermes.command」。Windows 使用 WSL，详见教程。

第一次使用 · 三步完成

打开完整新手教程 ↗（也可离线打开 docs/开始阅读.html）

  1. 体验演示。首页点击演示，确认页面能生成和下载报告。
  2. 添加关注并真实采集。默认附带三家公司；真实源需要网络，失败原因会明确显示。
  3. 逐步开启智能功能。填模型 → 勾选 AI 整理 → 安装 Hermes → 开启 Agent。无需一次配置所有功能。

完整教程在文件夹 docs/：新手教程、快速开始、常用操作、Agent 安装、常见问题。

密钥仅保存在本机 data/secrets.json。模型启用后，报告材料或任务上下文会发送给你配置的模型服务商。分享时请使用原始发布包，不要直接压缩使用后的文件夹。
